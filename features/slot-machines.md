# 🎰 Slot Machines

![Examples of the capsule machines in CobbledGacha](https://cdn.modrinth.com/data/cached_images/0436b16d5213a7c888d369ee0f1bbb0b5125a6ca_0.webp)

### Capsules full of surprises

These machines use a **gacha-style capsule system**: exchange the required in-game currency, receive a random capsule, then open it for a reward. They work differently from the reel-based slot game in the arcade.

### Using a machine

1. Check the machine’s instructions and accepted currency.
2. Make sure you have the required amount before using it.
3. Collect your capsule and open it to reveal the result.
4. Check what you received before deciding whether to try again.

### What might be inside?

The standard system uses **Relic Coins** and includes Poké, Great, Ultra, Master, and Cherish capsules. Reward pools can contain useful items such as fossils, vitamins, evolution stones, held items, and apricorns.

Other supported machine types may use different currencies or rewards. For example, a **Rocket Prize Master** uses a Koban Coin to provide a Rocket Ball containing a random Pokémon, when that machine is available.

### Keep it casual

Hikari Haven’s approach is **free-to-play fun using gameplay-earned currency**. Results are random; a particular prize is never guaranteed. Read the actual machine’s cost and reward information, and do not assume Arcade Coins or CobbleDollars are interchangeable with its currency.
