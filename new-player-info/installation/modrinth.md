# Modrinth

{% stepper %}
{% step %}
### Install Modrinth App

1. Download Modrinth off the [official page](https://modrinth.com/app).
2. Click the Download button.
3. Run the downloaded installer and follow the installation steps.

<figure><img src="../../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Set Up The Launcher

* Open the Modrinth App.
* Sign into your Minecraft Account.
{% endstep %}

{% step %}
### Installing The Modpack

* Click on the compass icon.

<figure><img src="../../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

* Type in **Hikari Haven Cobblemon**, and click the <mark style="color:$success;">**+ Install**</mark> button next to it.

<figure><img src="../../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Launching

* Once finished just hit the play button on the modpack to launch it


{% endstep %}
{% endstepper %}

{% hint style="warning" %}
It's advised to use at least 6GB of RAM with this modpack

You can edit your RAM by going to **Settings** -> **Synced settings** -> **Java and Memory**
{% endhint %}
